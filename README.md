# Angular: live coding

Два небольших файла из воображаемого платёжного кабинета. Кабинет открывается и в обычном браузере, и внутри WebView мобильного приложения (iOS и Android).

Код рабочий, но написан с ошибками. Задача — прочитать его вслух, найти проблемы и предложить, как переписать.

## Задания

1. [`src/app/deposit-amount.component.ts`](src/app/deposit-amount.component.ts) и [`deposit-amount.component.html`](src/app/deposit-amount.component.html) — компонент ввода суммы пополнения.
2. [`src/app/payment.service.ts`](src/app/payment.service.ts) — сервис платежей, который используют несколько форм.

На что смотреть:

- логика и корректность;
- RxJS: подписки, отмена запросов, утечки;
- производительность и change detection;
- безопасность;
- работа в WebView и SSR;
- деньги, локализация, типизация, стиль кода.

Порядок не важен. Можно сразу править код, можно оставлять комментарии прямо в файле.

## Как редактировать в браузере

1. Нажмите <kbd>.</kbd> на странице репозитория: откроется github.dev (VS Code в браузере).
2. Правьте файлы. Чтобы сохранить изменения, сделайте форк, когда github.dev предложит.

Сборка и запуск не нужны.
